# Checklist

- [x] 主编辑器实时预览可用时，按空格能在播放和暂停之间切换。
- [x] 主编辑器实时预览可用时，按左方向键跳到上一帧，按右方向键跳到下一帧。
- [x] 快捷键逐帧后，预览播放头和外层时间线播放头保持同步。
- [x] 输入框、按钮、滑块、下拉框或 contenteditable 聚焦时，空格和左右方向键不会触发全局预览快捷键。
- [x] 处理空格快捷键时页面不滚动；未处理的按键保留浏览器默认行为。
- [x] 实时预览画布与面板边界、标题、控制条、信息区之间有稳定内边距，画布不贴边。
- [x] 主编辑器三栏布局下，预览区、媒体区、Inspector 和时间线没有互相遮挡。
- [x] 窄屏宽度下，播放按钮、上一帧、下一帧、播放头滑块和指标折叠控件仍可见可操作。
- [x] 实时信息区默认展开，继续显示 Source、预览分辨率、FPS、队列、缓存、丢帧、活跃资源和 A/V drift 等指标。
- [x] 实时信息区可以折叠，折叠后保留包含 Source、FPS、JS Heap 或 `N/A` 的紧凑摘要。
- [x] 折叠控件具备正确的 `aria-expanded` 状态。
- [x] 展开状态下，内存/资源健康指标单独占一行。
- [x] `JS Heap` 展示当前页面 JS heap 的 used、total、limit 中可用字段，并明确不是整机内存或 Worker heap 精确值。
- [x] `performance.memory` 不可用时，JS Heap 显示 `N/A`，不会推断或伪造内存数据。
- [x] 内存/资源行展示 Storage usage/quota、活跃资源、活跃 VideoFrame、视频/音频解码队列和背压计数中的可用数据。
- [x] 相关组件测试或 Vitest 覆盖快捷键、焦点保护、折叠状态和内存指标不可用场景。
- [x] 相关 Playwright 用例覆盖空格播放/暂停、左右方向键逐帧、指标区折叠和主编辑器布局回归。
- [x] 相关 `pnpm` 验证命令通过，失败时能定位到具体预览交互或布局问题。
