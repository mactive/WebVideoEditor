# Checklist

- [x] 时间线顶部不再显示原生播放头 range slider。
- [x] 时间线显示带时间戳的刻度尺，包含主刻度、次刻度和可读时间标签。
- [x] 刻度尺的 `00:00` 位置与所有轨道 lane 的 0 秒位置完全左对齐。
- [x] 刻度尺宽度与轨道 lane 宽度一致，并随时间线总长变化同步。
- [x] 刻度尺刻度间距、轨道背景网格和 clip 位置使用同一套 `pixelsPerSecond` 换算。
- [x] 调整缩放后，刻度尺、clip 宽度、轨道网格和红色参考线仍保持对齐。
- [x] 点击刻度尺任意位置会更新播放头到对应时间。
- [x] 在刻度尺上拖动会连续更新播放头，并夹紧在 `0` 到时间线总长之间。
- [x] 当前播放头时间文本与刻度尺点击/拖动后的时间一致。
- [x] 预览面板能继续跟随时间线播放头变化。
- [x] 红色垂直参考线显示在当前播放头位置。
- [x] 红色参考线贯穿刻度尺和所有可见轨道 lane。
- [x] 红色参考线不覆盖左侧轨道标题和删除按钮。
- [x] 红色参考线不拦截 clip 移动、跨轨拖动和左右裁剪手柄的指针事件。
- [x] 横向滚动时间线后，红色参考线仍与对应时间位置一致。
- [x] 时间线总长预设、精确输入和缩放控制保持现有功能。
- [x] 轨道重排、轨道删除、clip 跨轨拖动和 clip 裁剪行为不因刻度尺改造回归。
- [x] 相关 editor interaction 测试已更新，不再依赖被移除的时间线播放头 slider。
- [x] `pnpm --filter @web-video-editor/editor typecheck` 通过。
- [x] 相关 editor 测试通过。
