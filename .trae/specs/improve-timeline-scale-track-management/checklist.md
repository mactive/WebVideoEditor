# Checklist

- [x] Project Document 支持保存用户配置的时间线总时长，旧工程无配置时仍能打开。
- [x] 时间线实际总长始终不小于最长 clip/text 内容末尾。
- [x] 用户可以选择 `1min`、`3min`、`5min`、`10min` 预设总时长。
- [x] 用户可以输入精确总时长。
- [x] 输入总时长小于内容末尾时，系统不会裁掉内容，并会给出明确提示。
- [x] 添加短素材后，已设置的长时间线范围不会自动收缩。
- [x] 时间线缩放控制只改变显示密度和横向滚动，不改变任何 clip/text 时间数据。
- [x] 播放头 range、标尺、clip 宽度和拖动换算都基于当前显示总长与缩放状态。
- [x] 视频、音频和文字轨道都可以通过拖动改变上下顺序。
- [x] 轨道重排通过 Command Bus 提交，并能 Undo/Redo。
- [x] Track `order` 是时间线显示顺序、视频叠放顺序、文字叠放顺序和导出叠放顺序的唯一来源。
- [x] 视频、音频和文字轨道都可以删除。
- [x] 删除空轨道会移除 Track 并归一化剩余轨道 order。
- [x] 删除含内容轨道前有确认；确认后会级联删除该轨道上的 clip 或 text。
- [x] 删除轨道后 selected clip/text、target video/audio track 和 session 状态不引用已删除实体。
- [x] 删除最后一条同类型轨道时有明确且一致的保护策略。
- [x] 视频片段可以从一个视频轨拖到另一个视频轨，并更新 `trackId` 与 `timelineStartUs`。
- [x] 音频片段可以从一个音频轨拖到另一个音频轨，并更新 `trackId` 与 `timelineStartUs`。
- [x] 文字片段可以从一个文字轨拖到另一个文字轨，并更新 `trackId` 与 `startUs/endUs`。
- [x] 跨类型拖动不会提交，例如视频到音频、音频到文字。
- [x] 跨轨拖动仍遵守目标轨道同轨不重叠约束。
- [x] 目标轨道时间冲突时，系统会阻止提交或夹紧到最近合法位置，并提供 UI 反馈。
- [x] 跨轨拖动通过 Command Bus 提交，并作为单个连续拖动事务参与 Undo/Redo。
- [x] 轨道删除后预览、音频播放和导出不会引用已删除轨道或内容。
- [x] 相关 domain/editor/preview-runtime/export Vitest 通过。
- [x] editor typecheck 通过。
- [x] 相关 Playwright 用例通过，覆盖总时长、缩放、轨道重排、轨道删除和视频跨轨拖动。
- [x] docs:check 通过。
- [x] 文档说明时间线总时长、缩放、轨道排序/删除和跨轨拖动语义。
